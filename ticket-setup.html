Internal setup

Mail από info@ στα ticket

Το FormSubmit / Formspree δεν μπορούν να στείλουν ως info@fitsolutions.gr. Χρειάζεται Google Apps Script με login στο info@.

Προϋπόθεση

Το info@fitsolutions.gr πρέπει να είναι Google Workspace ή Gmail. Αν είναι cPanel/άλλος πάροχος, πες το στον agent.

Βήματα

  1. Άνοιξε Chrome και κάνε login ως info@fitsolutions.gr
  2. Πήγαινε: script.google.com → New project
  3. Σβήσε τον default κώδικα και κόλλα όλο το αρχείο: scripts/ticket-mail.gs
  4. Save (δισκέτα) — όνομα π.χ. FITSOLUTIONS Tickets
  5. Deploy → New deployment
  6. Εικονίδιο γραναζιού δίπλα στο Select type → Web app
  7. Description: tickets
  8. Execute as: Me (info@fitsolutions.gr)
  9. Who has access: Anyone
  10. Deploy →Authorize / Allow
  11. Αντιγράψε το Web app URL (τελειώνει σε /exec)
  12. Στείλ’ το στο Cursor chat

Τι θα γίνει μετά

Ο agent βάζει το URL στη φόρμα ticket. Τότε:

  • Εσύ παίρνεις το ticket στο info@
  • Ο πελάτης παίρνει αγγλικό mail From: info@fitsolutions.gr
