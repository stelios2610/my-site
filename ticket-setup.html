Internal setup

Mail από info@ (HMailServer)

Το site είναι στο GitHub Pages. Το info@fitsolutions.gr είναι στο HMailServer. Άρα το ticket πρέπει να στέλνει mail από μικρό PHP endpoint στον server σου.

Βήματα στον server

  1. Βεβαιώσου ότι έχεις IIS + PHP (ή Apache + PHP) στο μηχάνημα του HMail (ή σε μηχάνημα που μιλάει SMTP στον HMail).
  2. Κατέβασε τον φάκελο server-ticket από το repo: github.com/stelios2610/my-site/server-ticket
  3. Βάλ’ τον στο web root, π.χ. C:\inetpub\wwwroot\ticket\
  4. Αντιγράψε config.sample.php → config.php και βάλε κωδικό info@
  5. SMTP τοπικά: host 127.0.0.1, port 25
  6. Άνοιξε το site στο IIS και σημείωσε το URL, π.χ. https://tickets.fitsolutions.gr/ticket.php
  7. Στείλε αυτό το URL στο Cursor chat

Αποτέλεσμα

Ο πελάτης παίρνει αγγλικό mail From: info@fitsolutions.gr μέσω HMailServer. Εσύ παίρνεις το ticket στο ίδιο mailbox.
